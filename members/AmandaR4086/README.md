# 我的 Git 学习笔记



第一次 Git 实验总结



1\. git add 的作用是：把工作目录里的修改添加到暂存区（index），让 Git 开始追踪这些改动，标记哪些内容要纳入下一次提交。

2\. git commit 的作用是：把暂存区里的内容做成一个永久快照，存进本地版本库，生成一个带唯一 SHA-1 哈希的提交记录，形成可追溯的版本链。

3\. git restore notes.md 的作用是：丢弃工作区中未暂存的修改，把 notes.md 还原到暂存区（或版本库）里的最新版本。

4\. commit 与 push 的区别是：commit 只把改动保存在本地仓库，别人看不到；push 才把本地的提交上传到远程仓库（如 Gitee），让协作者能通过 pull/fetch 获取到这些改动。
